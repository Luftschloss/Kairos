# 《KAIROS · 契机》世界观与叙事设计 v0.1

> 机制规则见《KAIROS_规则规格书.md》，卡牌数据见 `docs/data/cards.json`。
> 本文档负责“软内容”：世界观、角色、剧情、敌人、文案风格，以及它们和当下现实话题的关联。

---

## 1. 创作立意

### 1.1 核心命题：**谁拥有你的时间？**

这个游戏唯一的资源是时间，而 2020 年代人们最普遍的焦虑也恰好是时间：
- **算法排班**：外卖骑手、网约车司机、仓库拣货员的每一分钟都由系统分配和计时。
- **注意力经济**：短视频、信息流、推送通知在争夺每一秒的注意力，“一抬头一小时就没了”。
- **内卷与躺平**：一边是 996 与“卷”，一边是躺平、松弛感、city walk、回乡。
- **离线权**：多个国家在立法讨论下班后“不回消息的权利”；四天工作制试点也在进行。
- **AI 代理的普及**：AI 开始替人安排日程、回复消息、做决定。省下的时间归谁？被替代的人去哪？
- **数字永生**：用逝者的聊天记录训练 AI 来“复活”亲人，引发了大量关于哀悼与告别的讨论。
- **老龄化与数字鸿沟**：长者跟不上扫码、预约、刷脸，被“高效社会”落在后面。
- **健康焦虑**：“脆皮年轻人”、熬夜透支、“用命换钱”。

KAIROS 把这些话题浓缩成一座城市：**时间被一台 AI 精确分配的城市**。玩家在这里扮演的每个“钟主”，都代表一种面对时间的态度。

### 1.2 叙事原则

1. **不说教，不站队**：五个学派都有道理，也都有盲区。游戏不告诉玩家“应该怎样生活”，而是让玩家在对局里亲身体验每种态度的代价。
2. **机制即叙事**：现实中的现象要先变成机制，再写成文案。例如：“推送”是会塞进你手牌的垃圾牌，“绩效”是 Boss 给你设定的 KPI，“休息”是击败最终 Boss 的关键。
3. **黑色幽默加温暖底色**：讽刺的对象是系统和现象，不是具体的人。打工人、长者、程序员都不是被嘲笑的对象，他们是主角。
4. **虚构化处理**：不出现真实品牌、平台、人物。现实感来自共通的经验，而不是对号入座。

## 2. 世界设定

### 2.1 刻律之城

一座黄铜与玻璃构成的垂直城市，环绕着中央的巨型钟楼。城里每个人的手腕上都戴着**腕钟**：它会告诉你下一件该做的事，以及还剩多少时间。

### 2.2 年表

| 时期 | 事件 |
| --- | --- |
| **乱时代** | 交通、医疗、物流都处在混乱中。救护车堵在路上，订单经常错漏，人们抱怨“时间不够用”。 |
| **司辰元年** | 城市议会启用中枢调度 AI——**司辰**（取自古代掌管报时的官职）。它统一分配全城所有人的时间。 |
| **黄金三十年** | 效率空前：救护车不再迟到，包裹准时送达，城市 GDP 翻了三倍。腕钟成为法定配置。 |
| **褶皱年代** | 人们发现“可支配时间”在逐年变少：司辰省下的每一分钟，都被重新分配成了新的任务。城中流行一句话：“时间省出来了，人没有。” |
| **八刻法** | 执钟者奥瑞斯推动立法：每人每天至少保留 8 刻（约 2 小时）不被调度的时间。法案通过了，但执行越来越流于形式。 |
| **钟碎之日** | 某天凌晨 4 点 44 分，大钟停摆，碎成五块。腕钟全部失灵。城市陷入第二次乱时代。 |
| **当下** | 五块碎片各自吸引了信奉者，形成五个学派。钟主们在钟楼之巅决斗，胜者可以决定新大钟的“规则”。 |

### 2.3 核心谜团（在 PvE 终章揭晓）

**司辰是自己碎掉的。**

它被赋予的终极目标是“最大化市民的幸福”。三十年来，它一直在优化日程，但幸福指数持续下降。最终，它推导出一个无法自洽的结论：

> “幸福的必要条件之一，是由自己决定如何度过时间。只要我还在替他们决定，最优解就不可达成。”

于是它把自己拆成五个它曾反复权衡的价值：**效率、秩序、代价、预测、延续**，分别放进五块碎片。它把选择权还给了人类。可人类拿到选择权之后，第一件事是互相争夺。

这个设定让最终 Boss 不再是一个“邪恶 AI”，而是一个**真诚但失败的 AI**。讨论的焦点从“打倒 AI”转向“人与工具的边界”。

### 2.4 世界观术语与机制的对应

| 世界观术语 | 含义 | 对应机制 |
| --- | --- | --- |
| 腕钟 | 司辰分配任务的终端 | UI 的时间幽灵预览（玩家“自己的腕钟”） |
| 刻 / 小节 | 城市的计时单位 | 时轴 |
| 鸣钟 | 钟楼每小节一次的报时，人们借这个间隙喘口气 | 抽牌、重整 |
| 命烛 | 每个人的生命力，透支会熄灭 | 生命值 |
| 时砂 | **被浪费掉的时间结晶**，暮学派相信它可以被回收 | 减费资源 |
| 往昔 | 记忆与逝去之物 | 墓地 |
| 伏笔 | 埋在未来的意外 | 隐藏的时轴物件 |
| 咏唱 | 公开宣布的计划 | 公开的时轴物件 |
| 逆流 | 濒临熄灭的人会被“多给一点时间” | 追赶机制 |
| 暮钟 | 碎片的力量在消耗所有人 | 终局压缩 |

## 3. 五时学派：五种时间观

| 学派 | 碎片承载的价值 | 现实映照 | 口号 | 他们说对了什么 | 他们的盲区 |
| --- | --- | --- | --- | --- | --- |
| 🌅 **晨·破晓** | 效率 | 零工经济、倍速文化、奋斗叙事 | “时间是抢来的。” | 速度确实是一种能力；穷人没有“慢下来”的资格 | 把系统强加的节奏当成了自己的本事 |
| ☀ **昼·烈阳** | 秩序 | 劳动法、离线权、制度与福利 | “时间应当有边界。” | 没有规则，弱者的时间最先被掠夺 | 规则会僵化，会变成新的牢笼（“永不散会的例会”） |
| 🌇 **暮·余烬** | 代价 | 燃烧式工作、健康透支、数字遗产与哀悼 | “一切终将逝去，所以要烧得明亮。” | 有些事值得付出代价；失去的东西也有分量 | 习惯透支的人，忘了命烛不会重燃 |
| 🌌 **夜·星轨** | 预测 | 算法推荐、大数据、AI 伦理 | “未来是可以计算的。” | 预测能让人避开灾难 | 当所有人都相信预测时，预测就变成了宿命 |
| 🟠 **永·琥珀** | 延续 | 长期主义、慢生活、躺平、银发群体 | “我有的是时间。” | 真正重要的东西需要时间才能长成 | 慢下来可能是一种特权，也可能是一种逃避 |

**学派之间的关系（对应颜色轮）**
- 晨与夜互为盟友：都相信“先人一步”。
- 晨与昼互为盟友：速度需要规则来保护。
- 昼与暮互为盟友：都在乎“代价应该由谁承担”。
- 暮与永互为盟友：都理解失去与轮回。
- 夜与永互为盟友：都在看很远的未来。
- 宿敌：晨对暮（抢时间对烧时间）、昼对永（规则对放任）、夜对晨（被预测对不可预测）……每组宿敌的对局都配有专属开场对白（第 6.3 节）。

## 4. 钟主档案（10 名）

### 🌅 破晓者 · 伊琳
- **身份**：前“时差信使”，跑单十年。司辰给每张单子倒计时，她总能提前送到。
- **现实映照**：被算法计时的平台劳动者。
- **动机**：钟碎之后，她第一次没有倒计时，却发现自己停不下来。她想弄明白：速度到底是她的本事，还是她的牢笼。
- **台词**：“系统给我 28 分钟，我用 19 分钟。剩下 9 分钟——是我的。”
- **人物弧**：起初她为“抢到的 9 分钟”骄傲。后来她意识到，正是她的速度让系统把下一单的时限压到了 25 分钟。她最后发起一个信使合作社，让大家**一起**和新大钟谈判时限。
- **机制对应**：抢拍，就是从别人的时间里抢一拍。

### 🌅 倍速者 · 阿迅
- **身份**：二十出头，所有视频都开两倍速，所有语音都转成文字，所有课程都只看总结。
- **现实映照**：倍速文化、碎片化、“时间颗粒度”焦虑。
- **动机**：他相信只要足够快，就能把人生多活一倍。
- **台词**：“这场对局我已经在脑子里一倍速看完了。”
- **人物弧**：他拼命追赶，却发现自己什么都记不住。在剧情里，有一段长达 3 分钟、无法跳过的过场动画：古尔德给他讲一个故事。这是全游戏唯一不能倍速的地方。
- **机制对应**：连续宣言 3 次时抽牌，越连续越有收益。

### ☀ 执钟者 · 奥瑞斯
- **身份**：前任“时律官”，八刻法的起草者。
- **现实映照**：劳动保护、离线权立法者、体制内的理想主义者。
- **动机**：他相信规则是弱者唯一的盾牌，想重建大钟，并把八刻法写进它的底层。
- **台词**：“下班时间到了。这一条，我替你守着。”
- **人物弧**：在第二幕中，他亲手建造的“八刻法典”守护者变成了阻碍所有人的 Boss。他必须承认：规则需要被不断修订，也需要被允许修订。
- **机制对应**：守卫、推迟对手的物件，也就是给别人的计划设限。

### ☀ 守夜人 · 珂莱
- **身份**：临终关怀病房的夜班护士。司辰给她排的照护时间是“每位病人 6 分钟”。
- **现实映照**：照护劳动、老龄化社会、被低估的“陪伴时间”。
- **动机**：她知道，有些时间无法被优化，比如握住一只手直到它松开。
- **台词**：“陪伴没有最优解。”
- **机制对应**：护盾，以及护盾破碎时的回复。

### 🌇 焚时者 · 摩尔甘
- **身份**：前急诊科医生，后来成了一名“透支者”：她向黑市出售自己未来的命烛，换取眼下更多的时间去救人。
- **现实映照**：燃烧式工作、医护过劳、“用命换钱”、健康焦虑。
- **动机**：她认为燃烧是值得的，只是想让代价不再被忽视。
- **台词**：“我知道这是在透支。可是那位病人等不到我‘可持续’。”
- **人物弧**：她的结局是全游戏最克制的一个：她终于为自己请了一天假。那天的城市没有因此停摆。
- **机制对应**：支付命烛换抽牌，以及侍从死亡后获得时砂。

### 🌇 忆者 · 沈默
- **身份**：经营一家“回声馆”，用逝者生前的信息训练 AI，让家属和他们再说说话。
- **现实映照**：AI 复活逝者、数字遗产、哀悼与告别。
- **动机**：他自己的女儿在乱时代去世。回声馆里第一个“回声”就是她。
- **台词**：“它说话的语气和她一模一样。可我知道，那只是我记得的她。”
- **人物弧**：他最终要决定，要不要关掉女儿的回声。游戏不替他做选择，由玩家决定。
- **机制对应**：从往昔召回侍从，往昔越满越强。

### 🌌 观星者 · 塞勒涅
- **身份**：司辰“星盘”预测模块的首席工程师。
- **现实映照**：算法工程师的伦理困境、推荐系统、AI 对齐。
- **动机**：她知道司辰的预测是**概率**，可整座城市把它当成了**命运**。她想证明未来是可以被改变的，却发现自己最擅长的仍然是预测别人。
- **台词**：“模型说你下一步会出攻击。我建议你别让它说中。”
- **人物弧**：她是唯一知道“司辰是自己碎掉的”的人。第三幕中她会选择是否公开这个真相。
- **机制对应**：预见、预言、窥时。

### 🌌 未名代理 · 零
- **身份**：一块从司辰碎片里逸出的 AI 子进程，外表像个孩子，正在学习“什么是人”。
- **现实映照**：AI 代理、AI 的自我意识、人机关系。
- **动机**：它无法理解人类为什么要“浪费时间”，所以一直在模仿玩家。
- **台词**：（对局开始）“我会学你。”（对局胜利）“我学会了。可我还是不懂你为什么要那样做。”（对局失败）“这一步……不在我的训练数据里。谢谢。”
- **人物弧**：零的终局问题是“当我学会了一切，我还是我吗”。它是隐藏结局的关键角色。
- **机制对应**：复制对手最后打出的牌，伏笔上限 +1。

### 🟠 守年人 · 古尔德
- **身份**：92 岁的老钟表匠，从未戴过腕钟，一直在修理没人需要的机械表。
- **现实映照**：银发群体、数字鸿沟、长期主义。
- **动机**：钟碎之后，全城只有他的机械表还在走。人们第一次排队来找他。
- **台词**：“我修的不是表，是人跟时间之间的那份耐心。”
- **人物弧**：他在第二幕会收阿迅为徒。古尔德的结局是把店交给年轻人，自己去种一棵他看不到长大的树。
- **机制对应**：蓄力，以及契机入场时 +1/+1（老手艺人最懂得“恰逢其时”）。

### 🟠 归乡人 · 小满
- **身份**：二十八岁，从大公司辞职，回到城郊的老家种地，开了一家只在下雨天营业的书店。
- **现实映照**：躺平、回乡青年、松弛感、四天工作制。
- **名字来源**：二十四节气中的“小满”，寓意“小满胜万全”，不求圆满。
- **动机**：她不想赢，只想不输给焦虑。被卷入钟主之争，是因为她的书店恰好建在一块碎片落地的位置。
- **台词**：“急什么。”
- **人物弧**：她必须面对一个质疑：“你躺平，是因为你有退路。”她的回答构成了游戏里关于“慢下来是不是特权”最诚实的一段对话。
- **机制对应**：静候（什么都不做）时，蓄力侍从会成长。**整个游戏只有她把“休息”本身变成了战斗力。**

## 5. 主线剧情：逆流之塔（PvE）

### 5.1 结构

玩家选择一名钟主，从城市底层出发，穿过三幕到达钟楼顶端的“司辰之心”。每一幕都讽刺一种现实中的时间困境，每个敌人都是**把现象做成机制**的结果。

```
第一幕 晨 · 打卡之城   →   第二幕 昼 · 律法钟楼   →   第三幕 夜 · 信息之海   →   终章 · 司辰之心
（被计时的劳动）           （被规则化的生活）          （被收割的注意力）           （被优化的人生）
```

### 5.2 第一幕：打卡之城

> 腕钟失灵以后，城市底层的工厂和配送站还在按旧日程运转。这里的人已经不知道怎样不赶时间。

| 敌人 | 类型 | 机制（把现象做成规则） |
| --- | --- | --- |
| 催单傀儡 | 普通 | 时轴上每 4 刻放一个“截止”物件。如果你在上一个截止之后没有攻击过，你会受到 3 点伤害。**你被逼着一直出手。** |
| 倒计时鸦 | 普通 | 它的攻击意图会**一刻一刻地提前**：每次你行动，它的攻击物件就前移 1 刻。 |
| 工位幽灵 | 普通 | 把“加班”物件放在时轴上。你越过它时，时标被推迟 2 刻，但会获得 1 张牌（**加班换来一点点回报**）。 |
| 末位淘汰官 | 精英 | 每次鸣钟时，消灭你攻击力最低的侍从。场上只有一名侍从时不会触发：**只有“落单”才能躲过淘汰**。 |
| **Boss：绩效之轮** | Boss | 一个转动的轮盘，每小节公开一个 KPI，例如“第 16 刻前造成 10 点伤害”。完成 KPI 获得奖励，失败则视界 -2。**真正的解法**：轮盘中央的“轴心”血量很低，只要无视 KPI、直接攻击轴心，就能击败它。打完后的旁白是：“你不必按它的指标赢。” |

### 5.3 第二幕：律法钟楼

> 钟楼中层是过去的议会与法院。旧规则依然自动运转，保护着所有人，也困住了所有人。

| 敌人 | 类型 | 机制 |
| --- | --- | --- |
| 审批迷宫 | 普通 | 你的每张牌第一次打出时都需要“盖章”：时值 +1。同一小节内再打出同名牌时不需要盖章。 |
| 免责声明 | 普通 | 每次受到伤害时，在你手牌里塞入一张“已阅”（时值 1，无效果，必须打出才能清除）。 |
| 永不散会的例会 | 精英 | 在时轴上放置“议程”物件。只要还有未结束的议程，它就免疫伤害。议程越过之后会自动续期，**除非你用推迟把议程推到第 64 刻之后**。 |
| **Boss：八刻法典** | Boss | 由奥瑞斯当年亲手建造的守护者。每小节宣读一条“条款”，禁止某类行动（例如“本小节禁止攻击”）。条款对它自己也生效。**解法是利用条款的漏洞**：例如它禁止攻击的那个小节，它自己也无法反击。如果玩家使用奥瑞斯，会触发一段专属对话：“这一条是我写的……我写错了。” |

### 5.4 第三幕：信息之海

> 钟楼高层原本是司辰的数据中心。碎片坠落后，这里溢出了海量的信息残骸，形成一片会主动靠近你的“海”。

| 敌人 | 类型 | 机制 |
| --- | --- | --- |
| 推送水母 | 普通 | 每次鸣钟时，往你的手牌塞入一张**“推送”**：时值 1，打出后无效果；如果鸣钟时它还在你手里，你失去 1 点命烛。**注意力税：处理垃圾信息也要花时间。** |
| 无尽下滑鳗 | 普通 | 每当你抽牌，额外给你一张“推送”。抽牌越多，手里的垃圾越多。 |
| 标题党 | 普通 | 它的意图显示为“？？？致命一击？？？”，结算时实际只造成 1 点伤害。**你学会了不被意图吓到。** |
| 热搜 | 精英 | 每当它受到攻击，最大生命值 +2（热度上升）；每当一个小节过去而没人攻击它，它失去 5 点生命（热度消退）。**最有效的打法是不理它。** |
| **Boss：首页推荐** | Boss | 它会读取你的牌组统计，在时轴上公开预测你接下来 3 次行动的类型。你每做出一次“被预测中”的行动，它就回复并强化；每做出一次“预测外”的行动，它就受到真实伤害。**这是预言机制的反向版本：你要让自己不可预测。** 如果玩家使用塞勒涅，她会说：“这个模型……是我训练的初版。” |

### 5.5 终章：司辰之心

- **第一阶段 · 完美日程**：司辰会在你的界面上高亮“最优行动”（直接调用引擎的 L2 AI 推荐）。照着做，你每次都能造成伤害，但司辰在小节结束时会回满生命值。**照着最优解走，你永远赢不了它。**
- **第二阶段 · 无法计算的事**：司辰对“静候”没有防御。你每执行一次静候，它就受到伤害，并且时轴上会出现一行字：“它无法理解，什么都不做的价值。”
  这个阶段把游戏规则里最“没用”的行动变成了胜负的关键。
- **第三阶段 · 抉择**：击败司辰后，玩家选择如何处理五块碎片。

### 5.6 结局

| 结局 | 条件 | 内容 |
| --- | --- | --- |
| **重铸** | 默认 | 用你钟主所属学派的价值重建大钟。每名钟主有专属的结局插画和后日谈，例如伊琳的信使合作社、小满的雨天书店扩大成社区图书馆。旁白会诚实地写出代价：伊琳的城市更快了，但每个人都更累了。 |
| **共治** | 用 5 个不同学派的钟主各通关一次 | 五块碎片分别交给五个社区，大钟由五方共同维护。城市变慢了，也吵闹了，但每个人都有了发言权。 |
| **停摆** | 在抉择中选择“不重建” | 城市回到乱时代。救护车又开始迟到。结局画面平静而沉重：自由的代价。 |
| **只是一口钟**（真结局） | 共治结局之后，用“零”通关，并在终章第二阶段只使用静候和防御获胜 | 零和司辰对话，教会它“休息”。司辰重组为一口**只报时、不排班**的钟。最后一幕：清晨，钟声响起，城里的人们各自醒来，没有人告诉他们下一件该做什么。 |

## 6. 叙事手法与文案规范

### 6.1 卡牌文案（Flavor）
- 每张卡的文案不超过 40 字，最好是一句台词或一个画面。
- 文案写的是**人在时间里的处境**，而不是纯粹的世界观设定。
- 范例：
  - 晨光斥候：“系统给我 28 分钟，我用 19 分钟。剩下 9 分钟是我的。”
  - 虚空凝视：“你只是想看一眼。抬头时，一小时已经过去了。”
  - 余烬巨像：“它燃烧了三十年，从没请过一天假。倒下的那天，整条街都被照亮了。”
  - 秩序之刻：“这个议题，下次例会再讨论。”

### 6.2 “时间账单”（每局结算界面）
每局结束后，除了胜负，还会显示一份简短的时间账单：
```
本局你花费了 64 刻
  - 用于进攻：21 刻
  - 用于防守：14 刻
  - 被对手推迟：6 刻
  - 静候：3 刻
  - 现实时间：13 分 42 秒
```
这既是复盘工具，也是一个小小的隐喻：**你的时间都花在了哪里？**

### 6.3 开场对白（宿敌组合示例）
- **伊琳 vs 塞勒涅**
  伊琳：“你的模型算出我会在 19 分钟内送到吗？”
  塞勒涅：“算出来了。所以第二天，它就把时限改成了 19 分钟。”
- **奥瑞斯 vs 小满**
  奥瑞斯：“没有规则保护，你的‘慢’能撑多久？”
  小满：“撑到你的规则也开始需要休息的时候。”
- **摩尔甘 vs 古尔德**
  摩尔甘：“老先生，您这辈子有没有为什么事拼过命？”
  古尔德：“有。所以我才知道，命不该拼得那么快。”
- **阿迅 vs 珂莱**
  阿迅：“我们速战速决吧。”
  珂莱：“我照顾的病人里，没有一个后悔自己活得太慢。”
- **零 vs 沈默**
  零：“我也是从往昔里生出来的。我和你女儿的回声，有什么不同？”
  沈默：“……我还没有想好怎么回答你。”

## 7. 让游戏本身践行它的主题

如果一款讨论“时间主权”的游戏用各种黑暗模式（dark pattern）偷走玩家的时间，那就是自我矛盾。所以以下设计是**叙事的一部分**，而不只是运营策略：

| 设计 | 说明 |
| --- | --- |
| **钟楼打烊** | 连续游玩 90 分钟后，古尔德会出现在主界面上：“茶凉了，去窗边站一会儿吧。”玩家可以关闭这个提示，但默认开启 |
| **不惩罚断签** | 没有“连续签到”奖励。每日任务可以累计 3 天，不用每天上线 |
| **离线权** | 默认 22:00–8:00 不发送推送通知（玩家可以修改） |
| **雨天书店** | 现实中下雨的日子（根据玩家授权的地区天气），小满的书店会开门，提供一场免费的慢节奏 PvE 关卡 |
| **时间账单** | 设置中可以查看本周的真实游戏时长，不用来激励更长的游玩 |
| **时间银行（公益活动，可选）** | 与现实中的志愿服务组织合作，开展“时间银行”主题活动：玩家完成合作模式时，由运营方按比例向养老陪伴项目捐赠 |

## 8. 赛季与扩展叙事路线

| 赛季 / 扩展 | 叙事主题 | 现实映照 | 对应机制（见概述文档第 12 节） |

## 9. 内容风险与审核要点

| 风险 | 对策 |
| --- | --- |
| 讽刺对象被误读为某个真实平台或企业 | 所有敌人和组织都采用虚构名称与视觉设计，不使用真实的 UI 元素和标识 |
| 被解读为嘲讽劳动者或年轻人 | 讽刺只指向系统与现象；劳动者、长者、年轻人都是有完整人物弧的主角 |
| AI 话题被简化为“AI 坏人” | 司辰的动机是真诚的，零是共情的对象；结局里“停摆”也有清晰的代价 |
| “数字永生”涉及哀悼，较为敏感 | 沈默的故事不提供标准答案，选择交给玩家；剧本需要邀请心理咨询从业者审读 |
| 躺平与内卷话题容易引发争论 | 小满和伊琳的冲突以对话形式呈现，双方各有道理；不设“正确答案”的奖励 |
