# KAIROS · 契机 — Demo 01

## 运行

- Unity **2022.3.62f3**，Built-in Pipeline，Legacy Input Manager；未升级项目版本。
- 最新 Windows 教学版：`Builds/KairosDemo-Tutorial/KairosDemo.exe`，保留同目录的 `_Data`、`MonoBleedingEdge` 与 DLL 一起运行；窗口关闭或 Alt+F4 退出。旧版 `Builds/KairosDemo/` 保留不覆盖。
- 打开 `Assets/Kairos/Scenes/KairosDemo.unity`，点击 **Play**。也可用菜单 **KAIROS → Open Demo**。
- 建议 Game 窗口最大化、16:9、至少 1280×720；界面按 1600×900 等比适配。中文字体使用系统 Microsoft YaHei 等字体，不含可分发字体资产。
- 主菜单点击预组按钮切换双方卡组，种子相同时可重现洗牌与先行者。

### 新手教学（建议先玩）

- 首次启动会推荐约 2 分钟的可操作教学；也可跳过。未完成教学时，选择普通模式会再次提供教学或直接进入的选择。
- 主菜单 **新手教学** 可随时重玩；完成后在本机记录进度，跳过/中途退出不记为完成。
- 教学使用固定残局：你在第 0 刻，训练钟偶在第 2 刻，仅有 4 命烛且逆流已用；跳过调度。**普通对局规则和初始状态不变**。
- 五步：打出晨光斥候 → 选择斥候与钟偶并攻击 → 同刻后到者连续行动，蓄势到第 4 刻 → 观察鸣钟抽牌/重整/视界提升，让钟偶静候 → 再攻击获胜。
- 所有行动由正式规则引擎结算。每步仅开放目标操作，以金色边框提示；没有倒计时，钟偶不会自动催促。
- 教学完成可直接进入 AI 练习、重玩或返回主菜单。教学不提供普通对局回放导出，避免把特殊开局当作常规回放。
- 主菜单与对局右上角的 **规则手册** 提供五类说明：入门与操作、时轴与鸣钟、战斗与关键词、抢拍与未来、资源与终局。对局中打开手册会保留选择并暂停 AI/抢拍计时。
- 普通对局增加合法目标金色高亮与手牌上方的即时操作提示；视界不足、疲惫、守卫等情况会提示下一步。
- 当前教学聚焦最基础的时轴和战斗；抢拍、伏笔、咏唱等进阶机制先通过手册说明，未实现对应的互动教学关。

### PVP（本次优先）

**同机双人热座**，不是联网 PVP，符合规格书 17.1 的原型阶段。

1. 选择双方预组，进入本地 PVP。
2. 点击手牌标记调度，再确认；另一位玩家接手时有隐私遮罩。
3. 选择手牌或己方侍从，点目标，再点「确认行动」。无目标牌直接确认。
4. 卡牌可切换为盖放伏笔，`+1…+6` 从支付 2 刻后的时标计算。伏笔牌只能盖放。
5. 抢拍窗口只能抢拍或放弃，默认 8 秒自动放弃；交接遮罩与帮助/离开弹窗期间不消耗计时。
6. 效果选择中按顺序点牌，再指定置顶张数；未置顶的牌按所选顺序置底。
7. 结算页可导出回放到 `Application.persistentDataPath/Replays/`。回放含双方隐藏信息，只应赛后共享。

### AI 与 PVE

- **对战练习**：两套 30 张预组，本地贪心 AI。AI 只读取裁剪视图，不偷看牌库或对手手牌。
- **逆流之塔**：10 张起始牌组 → 三场战斗（末场 Boss）→ 前两场各有三选一奖励/跳过 → 休整治疗 6 或删牌 → 通关/失败。
- 命烛与牌组在本次旅程内延续；战斗间重建时轴和牌库。没有跨会话存档。
- 敌人目前复用卡牌 AI；获得行动权后显示即将执行的行动、目标与前后刻数。伏笔仍隐藏内容。
- 「催单傀儡／工位幽灵／绩效之轮」当前是流程占位敌人，**未实现**世界观中的截止、加班、KPI/轴心专属机制；不是完整 Roguelike 第一幕。

## 实现内容

- 纯 C# `Kairos.Engine`，`noEngineReferences`；C# 9，带种子的 xoshiro128** RNG，整数规则计算、手写状态克隆。
- 46 张卡牌与 10 名钟主数据加载，效果 DSL 在加载时转为类型化节点；界面先开放文档的两套预组与对应钟主。
- 调度、牌组校验、后到者先行、时间支付、视界、鸣钟、守卫/迅捷/停滞/蓄力、同时战斗伤害、护盾、时砂、契机、连拍。
- 一层抢拍与反制、锁定费用、失效照付时间、伏笔/虚张声势、咏唱锁定目标、预言、部署/余音与被动触发。
- 预见/窥时/往昔召回暂停选择、手牌上限焚毁、疲劳、逆流、暮钟、时尽判定。
- 热座隐藏信息交接、卡面与场面、整条时轴、选择后的落点标记、悬停数值预览、未来物件目标列表、结算与 JSON 回放。
- 原有 `Assets/Scenes/SampleScene.unity` 未改动；新 Demo 场景已加入 Build Settings。

## 边界与后续工作

- 这是可玩的技术 Demo，不是规格书所有生产级需求的最终实现。
- 尚无联网服务器、匹配/账号、构筑编辑器、进阶机制互动教学、回放播放器、正式美术/音效/动画、移动端触摸专项适配、跨平台字体资源。
- 尚无 ISMCTS、真正的参数扫描/平衡验收。100 局中破晓星轨仅赢 15 局（简单 AI + 固定对阵）；这不是先行者胜率，也不能据此宣称达到设计 KPI，应优先做人类试玩与 AI 改进。
- 扩展用历法、净耗时自我后退护栏（T35）等不在当前基础卡池中，未完成验收。回声仅有基础处理，未作为本次已验证功能。
- 当前目标枚举适配基础卡池的单目标卡；新增多目标卡、更多选择组合、可消失的生命光环等需要扩展与专门测试。
- 数据校验覆盖牌组、未知 op、被动选择禁令等，但不是完整 JSON Schema 校验器；继续扩卡前补齐引用、必填参数、范围与光环生命周期校验。
- 当前 UI 每次决策重建面板，适合低频卡牌 Demo；大规模动效/移动设备版本应改为增量绑定和对象复用。
- 建议人工连续玩三局：快攻对控制、双镜像；重点体验抢拍交接频率、伏笔位置选择、精确鸣钟与选牌可读性。
