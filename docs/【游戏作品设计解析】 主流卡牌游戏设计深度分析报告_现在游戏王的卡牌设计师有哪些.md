## 一、引言

**卡牌游戏（Card Game）** 作为一种兼具策略深度和娱乐性的游戏形式，经历了从 实体集换式卡牌（TCG） 到 数字卡牌游戏（CCG/DCG） ，再到 **Roguelike卡牌构筑（DBG）** 的漫长演化。本报告将对六款具有里程碑意义的主流卡牌游戏进行深度设计分析，揭示它们各自的设计哲学、核心机制和创新亮点。

---

### 二、各游戏详细分析

---

#### 1\. 🧙 万智牌（Magic: The Gathering, MTG）

**基本信息：** 1993年由数学家理查德·加菲尔德（Richard Garfield）设计，威世智（Wizards of the Coast）发行，是 **全球首款集换式卡牌游戏（TCG）** ，被誉为卡牌游戏的"鼻祖"。

##### 核心机制设计

| 机制维度 | 设计详情 |
| --- | --- |
| **资源系统** | **地牌（Land）系统** ——玩家需从手牌中打出"地牌"来获取"法术力（Mana）"，每回合至多打一张地。这是TCG史上首个"资源需从牌组中抽取"的设计，产生了"卡地（mana screw）"和"爆地（mana flood）"的经典风险博弈 |
| **颜色轮（Color Pie）** | 白、蓝、黑、红、绿五大颜色，每个颜色代表独特的哲学理念和机制特色（白=秩序/防御，蓝=知识/控制，黑=死亡/牺牲，红=混沌/速攻，绿=自然/成长），形成了卡牌游戏史上最经典的 **颜色身份系统** |
| **堆叠系统（The Stack）** | 咒语和异能以"后发先至"的方式在堆叠上结算，允许双方玩家在任何时机使用瞬间（Instant）进行响应，创造了 **极其深度的互动博弈** |
| **卡牌类型** | 地、生物、法术、瞬间、结界、神器、鹏洛客等，类型丰富且规则严谨 |
| **回合结构** | 重置→维持→抓牌→主阶段→战斗→主阶段→结束，阶段精细且严谨 |

##### 特色与创新

- **颜色轮设计** ：被认为是游戏设计史上最优雅的"职业分类系统"，被无数后来的游戏借鉴
- **堆叠与优先权系统** ：创造了"响应式博弈"的概念，让对手回合也能参与互动
- **极其丰富的赛制** ：标准、摩登、薪传、特选、限制赛（轮抽/现开）、指挥官等，生态多元
- **持续30+年的机制迭代** ：每年推出新系列和新关键词机制，保持生命力

##### 优缺点分析

| ✅ 优点 | ❌ 缺点 |
| --- | --- |
| 策略深度极高，几乎无穷的组合可能 | 入门门槛极高，规则书厚达数百页 |
| 颜色轮设计优雅，身份感强烈 | 地牌系统容易导致"卡地/爆地"的不良体验 |
| 实体+数字双轨运营，生态完善 | 卡牌价格高昂，构筑成本大 |
| 堆叠系统互动性极强 | 对局时间长，不适合碎片化时间 |

#### 2\. ⚔️ 游戏王（Yu-Gi-Oh!）

**基本信息：** 源自高桥和希1996年的漫画作品，由KONAMI开发为集换式卡牌游戏。是 **全球销量最高的TCG之一** （吉尼斯世界纪录认证），以动漫IP驱动。

##### 核心机制设计

| 机制维度 | 设计详情 |
| --- | --- |
| **资源系统** | **无费用系统！** 游戏王是主流TCG中罕见的 **没有法力水晶/能量等地牌资源系统** 的游戏。玩家每回合可进行一次通常召唤，魔法卡使用无费用限制，这意味着只要手牌允许， **第一回合就能展开巨大的场面** |
| **卡牌类型** | 怪兽卡（通常/效果/仪式/融合/同调/超量/灵摆/连接）、魔法卡（通常/仪式/装备/永续/速攻/场地）、陷阱卡（通常/永续/反击） |
| **额外卡组（Extra Deck）** | 融合/同调/超量/连接怪兽存放在独立的额外卡组中，通过特定条件从额外卡组召唤，这是游戏王最具标志性的系统之一 |
| **连锁系统（Chain）** | 类似万智牌的堆叠，后发先至。但分为"咒文速度"等级，决定哪些效果可以连锁哪些 |
| **后场盖卡（Set）** | 陷阱卡可面朝下盖放，对手无法预知，创造了独特的 **心理博弈和信息不对称** |

##### 特色与创新

- **无费用系统** ：打破了"每回合只能做有限的事"的传统框架，允许极高的操作上限和Combo（连招）展开
- **额外卡组系统** ：从融合→同调→超量→灵摆→连接，不断进化的召唤法是整个游戏进化的核心引擎
- **"说书"体验** ：由于无费用限制，一回合内可以执行极长的操作链，被玩家戏称为"说书"
- **手坑（Hand Trap）** ：因为先手展开过于强大，衍生出大量从手牌发动的干扰卡（如灰流丽、增殖的G），形成独特的博弈层

##### 优缺点分析

| ✅ 优点 | ❌ 缺点 |
| --- | --- |
| 无费用系统带来极致的Combo体验 | 先手优势巨大，猜拳（先后手决定）影响极大 |
| 动漫IP加持，情怀与收藏价值并存 | 规则复杂度极高，K语言（效果文本）晦涩难懂 |
| 额外卡组系统不断创新召唤法 | 卡池过深（10000+张），新人学习成本巨大 |
| 盖卡系统带来心理博弈乐趣 | 环境固化严重，禁限卡表调整频繁引发争议 |
|  | 对手回合互动体验差（"看对面玩"的感觉） |

#### 3\. 🎮 宝可梦集换式卡牌游戏（Pokémon TCG, PTCG）

**基本信息：** 1996年在日本首发，由Creatures Inc.开发、任天堂/宝可梦公司发行。是全球收入最高的TCG之一，依托全球最强IP"宝可梦"。

##### 核心机制设计

| 机制维度 | 设计详情 |
| --- | --- |
| **资源系统** | **能量卡（Energy）** ——玩家每回合可从手牌附着1张能量卡到宝可梦身上，招式需要满足特定能量需求才能使用。基本能量卡无数量限制可任意投入 |
| **胜利条件** | **赏罚卡/奖品卡（Prize Cards）** ——游戏开始时设置6张奖品卡，每次击倒对手一只宝可梦可拿取1-2张奖品卡， **先拿完所有奖品卡的一方获胜** 。这是PTCG最具独创性的设计 |
| **卡牌类型** | 宝可梦卡（基础/进化）、训练家卡（物品/支援者/竞技场）、能量卡 |
| **进化系统** | 基础宝可梦→一阶进化→二阶进化，每回合可进化一次，模拟原作中的宝可梦成长 |
| **前场/后场** | 战斗区（前场，1只）+备战区（后场，最多5只），前场宝可梦才能攻击，也可撤退替换 |
| **属性相克** | 火、水、草、电、超能力等属性之间的弱点/抗性系统 |

##### 特色与创新

- **奖品卡机制** ：这是PTCG区别于其他所有TCG的核心设计。它创造了独特的"追赶机制"——落后方只要击倒对手的大宝可梦就能拿多张奖品卡，翻盘可能性始终存在。同时也让 **大型宝可梦成为"双刃剑"** （强力但被击倒时对手拿2张奖品卡）
- **IP与玩法的高度融合** ：进化系统、属性相克、宝可梦捕捉等概念完美还原了原作世界观
- **全年龄友好** ：规则相对简洁，低龄玩家也能快速上手，但竞技层面策略深度不低

##### 优缺点分析

| ✅ 优点 | ❌ 缺点 |
| --- | --- |
| 奖品卡机制独创性强，翻盘感好 | 能量卡系统容易导致"卡能量"的不良体验 |
| IP影响力全球第一，受众极广 | 强IP依赖，非宝可梦粉丝可能缺乏代入感 |
| 规则相对友好，适合全年龄 | 支援者卡限制（每回合1张）限制了Combo深度 |
| 收藏市场活跃，卡牌保值性好 | 部分强力卡组高度依赖特定支援者卡 |

#### 4\. 🔥 炉石传说（Hearthstone）

**基本信息：** 2014年由暴雪娱乐（Blizzard Entertainment）开发，基于《魔兽世界》世界观。是 **数字卡牌游戏（CCG）的里程碑** ，开创了电子卡牌的新时代。

##### 核心机制设计

| 机制维度 | 设计详情 |
| --- | --- |
| **资源系统** | **法力水晶自动增长** ——每回合自动获得1颗法力水晶（上限10颗），无需从牌组中抽取。这是对万智牌地牌系统的 **革命性简化** ，彻底消除了"卡地"问题 |
| **英雄系统** | 每个职业有独特的 **英雄技能（Hero Power）** ，消耗2费可使用，提供了每回合的基础行动选项 |
| **卡牌类型** | 随从、法术、武器、英雄牌、地标等 |
| **关键字系统** | 嘲讽、冲锋、圣盾、亡语、战吼、发现等，设计简洁易懂 |
| **奥秘（Secret）** | 替代万智牌的瞬间响应系统，在对手回合自动触发，简化了互动复杂度 |
| **构筑规则** | 30张牌组，同名卡最多2张（传说卡最多1张） |

##### 特色与创新

- **"数字原生"设计理念** ：炉石是第一个真正为电子平台量身打造的卡牌游戏，大量利用了数字化的优势：
	- **随机性（RNG）** ：随机效果在电子平台上轻松实现
		- **发现机制（Discover）** ：从三张卡中选一张，创造了实体卡牌无法实现的体验
		- **衍生卡** ：战斗中创造新卡牌，极大拓展了策略空间
- **减法设计** ：取消了对手回合的响应（奥秘除外），让游戏更易上手
- **UI/UX标杆** ：极其出色的界面设计、音效和动画，成为行业标杆
- **多模式拓展** ：竞技场、冒险模式、酒馆战棋（Auto Battler）、佣兵战纪等

##### 优缺点分析

| ✅ 优点 | ❌ 缺点 |
| --- | --- |
| 上手门槛低，"易于上手，难于精通" | 对手回合互动极少，容易产生"无力感" |
| 法力水晶自动增长消除卡地问题 | 随机性（RNG）有时过大，影响竞技公平性 |
| UI/UX极其出色，视听体验极佳 | 退环境机制（标准赛制轮替）导致卡牌贬值 |
| 发现等数字原生机制创新性强 | 版本迭代中卡牌强度不断膨胀（power creep） |
| 多模式丰富，适合各类玩家 | 全卡收集氪金压力大 |

#### 5\. 🌙 影之诗（Shadowverse）

**基本信息：** 2016年由日本Cygames开发，是一款以日系二次元风格为特色的数字卡牌游戏。在炉石的基础上做出了显著的差异化设计。

##### 核心机制设计

| 机制维度 | 设计详情 |
| --- | --- |
| **资源系统** | **PP（Play Point）自动增长** ——类似炉石的法力水晶，每回合+1（上限10） |
| **进化系统（Evolve）** | ⭐ **影之诗最核心的独创机制！** 随从可消耗进化点进行进化，获得+2/+2属性提升和特殊效果，并获得"突进"（可立即攻击随从）。先手2个进化点（第5回合可用），后手3个进化点（第4回合可用） |
| **职业系统** | 8大职业（精灵、皇家护卫、巫师、龙族、死灵法师、吸血鬼、主教、复仇者），每个职业有独特的职业机制 |
| **卡牌类型** | 随从、法术、护符（Amulet） |
| **构筑规则** | 40张牌组（比炉石多10张），同名卡最多3张 |

##### 特色与创新

- **进化系统** ：这是影之诗与炉石最大的差异点。进化点是一种 **中盘资源管理** 的核心：
	- 先手/后手的进化点数量和可用回合不同， **有效平衡了先后手差距**
		- 进化时机选择创造了丰富的策略博弈
		- 部分卡牌进化后触发强力效果（进化时效果），形成了独特的构筑围绕点
- **职业差异化极强** ：每个职业都有独特的底层机制：
	- 精灵：连击（Combo）
		- 龙族：跳费（增加PP上限）
		- 死灵：墓场（利用已死亡的卡牌）
		- 吸血鬼：复仇（低血量触发效果）/自残
		- 主教：吟唱（倒计时护符）
- **日系美术与声优** ：高质量的二次元立绘和全程声优配音

##### 优缺点分析

| ✅ 优点 | ❌ 缺点 |
| --- | --- |
| 进化系统创造了独特的中盘博弈 | 后期版本卡牌强度膨胀严重 |
| 先后手平衡设计优秀 | 40张牌组导致一致性（consistency）较低 |
| 职业差异化极强，玩法丰富 | 部分职业机制过于复杂 |
| 美术和声优质量极高 | 国际影响力不如炉石 |
| 福利系统慷慨（送卡包多） | 模型膨胀导致游戏节奏越来越快 |

#### 6\. 🗡️ 杀戮尖塔（Slay the Spire ）

**基本信息：** 2017年由Mega Crit Games开发（2019年正式发售），是 **Roguelike卡牌构筑（Deck-building Roguelike）品类的定义者** ，开创了"爬塔 类 "游戏的全新品类。

##### 核心机制设计

| 机制维度 | 设计详情 |
| --- | --- |
| **游戏模式** | **单人PvE + Roguelike** ——非对战型卡牌，每次游玩从基础牌组开始，通过战斗和事件逐步构筑牌组，攀登三层尖塔 |
| **能量系统** | 每回合固定 **3点能量** ，打出卡牌消耗能量 |
| **卡牌类型** | 攻击（Attack）、技能（Skill）、能力（Power，永久生效） |
| **抽牌/弃牌循环** | 每回合抽5张牌，回合结束弃掉所有手牌，牌库抽完后洗入弃牌堆 |
| **遗物系统（Relics）** | 战斗中获取的被动道具，永久改变游戏规则（如每回合多1能量、额外抽牌等），与卡牌形成联动 |
| **地图系统** | 分支路线选择：普通战斗/精英战斗/休息/商店/问号事件/Boss |
| **角色系统** | 4个角色（铁甲战士/静默猎手/故障机器人/观者），各有完全独立的卡池和机制 |

##### 特色与创新

- **Roguelike + 卡牌构筑的完美融合** ：创造了全新的游戏品类，每次游玩都是一次新的构筑过程
- **卡牌+遗物双核心** ：遗物改变底层规则，卡牌提供战术选择，两者联动创造无限可能
- **敌人意图可见** ：怪物下一步的行动（攻击/防御/Buff）对玩家可见，将信息博弈做到极致
- **动态构筑决策** ：每次战斗后从3张卡中选1张加入牌组（或跳过），核心策略在于 **知道什么时候不拿卡** （保持牌组精简）
- **进阶系统（Ascension）** ：20个难度等级，每次通关解锁更高难度，极大延长游戏寿命
- **数值透明化** ：所有伤害/护甲/概率精确显示，让失败成为学习的阶梯

##### 各角色机制特色

| 角色 | 核心机制 | 设计特色 |
| --- | --- | --- |
| **铁甲战士（Ironclad）** | 力量（Strength）、自残 | 高攻高防，以血换力 |
| **静默猎手（Silent）** | 毒素（Poison）、小刀（Shivs） | 持续伤害+多段攻击 |
| **故障机器人（Defect）** | 充能球（Orbs：闪电/冰霜/暗黑/等离子） | 自动化的充能球循环系统 |
| **观者（Watcher）** | 姿态切换（平静/愤怒/神格） | 高风险高回报的姿态管理 |

##### 优缺点分析

| ✅ 优点 | ❌ 缺点 |
| --- | --- |
| 重玩价值极高，数百小时不腻 | 纯PvE，缺乏对战的社交乐趣 |
| 策略深度极高，决策紧凑 | 运气成分（发牌/遗物随机）有时令人沮丧 |
| 敌人意图可见，信息透明 | 高进阶难度下某些角色平衡性欠佳 |
| 角色差异化极强 | 单局时间较长（30-60分钟） |
| 品类定义者，影响深远 | 卡牌池有限，深度玩家可能探索殆尽 |

### 三、横向对比分析

#### 1\. 资源系统对比

| 游戏 | 资源类型 | 是否占用牌组空间 | 自动/手动 | 核心风险 |
| --- | --- | --- | --- | --- |
| **万智牌** | 地牌→法术力 | ✅ 是 | 手动打出 | 卡地/爆地 |
| **游戏王** | 通常召唤次数 | ❌ 否 | 每回合1次 | 无资源限制导致先手过强 |
| **宝可梦PTCG** | 能量卡 | ✅ 是 | 手动附着 | 卡能量 |
| **炉石传说** | 法力水晶 | ❌ 否 | 自动增长 | 几乎无资源风险 |
| **影之诗** | PP | ❌ 否 | 自动增长 | 几乎无资源风险 |
| **杀戮尖塔** | 能量 | ❌ 否 | 每回合固定3点 | 无（PvE设计） |

**设计启示：** 从万智牌到炉石/影之诗，资源系统经历了从"手动+占牌组"到"自动+不占牌组"的简化趋势。这一简化消除了"卡资源"的不良体验，但也减少了资源管理层面的策略深度。游戏王走向了另一个极端——完全取消资源限制，带来了极高的Combo上限但牺牲了平衡性。

### 四、总结与启示

#### 1\. 卡牌游戏设计的演化趋势

```cobol
1993 万智牌 ──────► 实体TCG的诞生（资源占牌组、堆叠响应）

      │

1996 游戏王 ──────► 无费用系统、额外卡组（IP驱动）

1996 宝可梦PTCG ──► 奖品卡机制（追赶系统创新）

      │

2014 炉石传说 ────► 数字CCG革命（自动资源、减法设计、数字原生机制）

      │

2016 影之诗 ──────► 差异化竞争（进化系统、职业深度）

      │

+
```

#### 2\. 核心设计启示

1. **资源系统是卡牌游戏的"地基"** ：从万智牌的地牌到炉石的自动水晶，资源系统的设计直接决定了游戏的节奏和体验。简化资源系统可以降低门槛，但也需要其他层面的策略深度来补偿。
2. **"减法"与"加法"的平衡** ：炉石在规则上做了大量减法（取消堆叠响应、取消地牌），但在数字原生机制上做了大量加法（发现、随机性、衍生卡）。好的设计需要知道"减什么"和"加什么"。
3. **先后手平衡是所有对战卡牌的核心问题** ：影之诗的进化点差异化分配、宝可梦的奖品卡追赶机制、游戏王的手坑系统，都是解决这一问题的不同思路。
4. **IP与玩法的协同** ：宝可梦PTCG和炉石传说证明了强力IP与优秀玩法的结合可以产生1+1>2的效果。而万智牌和杀戮尖塔则证明了纯粹的设计力量同样可以创造伟大的游戏。
5. **品类融合是创新的重要路径** ：杀戮尖塔将Roguelike与卡牌构筑融合，创造了全新品类。未来的卡牌游戏创新很可能来自更多跨品类的融合。

#### 3\. 未来展望

- **AI与卡牌设计** ：AI辅助的平衡性调整和卡牌设计将成为趋势
- **跨平台与实体化** ：影之诗推出的实体卡牌版（SVE）代表了数字→实体的反向路径
- **Roguelike卡牌的持续繁荣** ：杀戮尖塔2（2026年3月EA）的推出将延续品类热度
- **社交化与休闲化** ：酒馆战棋等模式的成功表明，卡牌游戏的社交化和休闲化是重要方向

---

> **结语：** 从1993年的万智牌到2017年的杀戮尖塔，卡牌游戏设计走过了一条从实体到数字、从对战到单人、从复杂到精简再回归深度的螺旋上升之路。每一款成功的卡牌游戏都在回答同一个问题： **如何在有限的规则框架内创造无限的策略可能？** 这个问题的答案，仍在不断演化之中。
