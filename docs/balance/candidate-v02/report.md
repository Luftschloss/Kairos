## 重构候选（未同步正式数据）

- `DAWN_COURIER`：疾行信使生命1→2：区分于1刻斥候，面对1攻守卫不再必然一换零；不提高迅捷爆发攻击。
- `DAWN_INTERCEPTOR`：拦截者可常规部署；保留2/2与抢拍重定向。消除抽到侍从却无法主动建立场面的结构性死牌。
- `DAWN_GALE_CHORUS`：疾风连奏2→1刻：减少增攻刚生效便鸣钟过期的落点，仍须规划下一次鸣钟，不能无脑在钟点前施放。
- `DAWN_SUNRISE_TORRENT`：曙光洪流5刻2/3伤→4刻3/4伤：最低视界时点从12提前至8刻，提供对铺场的确定性回答；不越过护盾，不伤钟主。
- `NOON_SUNDIAL_JUDGE`：日晷法官3/6节奏1→3/5节奏2：保留守卫与咏唱税的秩序身份，降低防守组件兼任低成本输出核心的效率。
- `NOON_COVENANT_OF_RADIANCE`：光辉圣约每钟回复2→1：两张叠加由4回复/钟降为2；仍须后续设计刻印互动，不能凭无限存续上界认为已经平衡。
- `ETERNAL_MOSS_WATCHER`：苔藓守望者1/3→1/2：不改蓄力核心，在第一次鸣钟前给予2伤解牌窗口；首钟后仍为2/3。
- `ETERNAL_RING_TREE`：年轮古树节奏1→2：成长体型不削，兑现高攻击必须付出时间，而非防守、成长、进攻三项都低代价。
- `K_DAWN_IRIN`：伊琳从只能重整当节新入场未攻击侍从，改为低费侍从再行动；冷却1→2钟，限制高攻大体型连击。符合信使协作而非重复迅捷。
- `K_DAWN_AXUN`：阿迅减费1→2：旧技能先付1再减1通常净收益0，且可能立刻鸣钟失效。新技能最多净省1刻；必须展示跨钟失效，不能按无条件收益计价。
- `K_ETERNAL_XIAOMAN`：小满静候成长增加每小节一次上限：双方反复静候时通常每次前进2刻、每自己小节约2次额外全场蓄力；限制重复空操作收益，保留等待成长。
- `PRECON_DAWN_NIGHT`：破晓星轨侍从12→18，保留两虚空凝视与两命运织者支撑伏笔/过牌，移除镜中之刻与天命预言，减少反制数量；新增流浪计时者/魔像形成中立场面骨架。不是把所有条件牌都改成纯体型。
- `PRECON_NOON_ETERNAL`：烈阳琥珀侍从20→18，用一张成长主题配合牌与一张过牌替换两魔像，维持防守成长身份而非全程纯体型密度压制。
