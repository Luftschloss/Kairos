# 《KAIROS · 契机》卡牌游戏原型设计文档 v0.1

> **一句话概述**：一款**没有回合、没有法力**的对战卡牌游戏。双方共享一条“时轴”，每张牌的费用就是**时间**——谁落后谁行动。你打出越强的牌，就要把越多的时间让给对手。
>
> **电梯演讲**：《Patchwork》的时间轨 × 《杀戮尖塔》的可见意图 × 《万智牌》的响应博弈 × 《游戏王》的盖牌心理战，最后用炉石式的简洁关键词把它们包起来。

- 类型：1v1 对战 CCG（核心）+ Roguelike PvE + 多人乱斗
- 平台：数字优先（PC / 移动端），使用 **Unity 6 LTS + C#** 开发；规则可直接实体化（桌游 / TCG）
- 单局时长：数字版 10–15 分钟，实体版 20–25 分钟
- 目标玩家：炉石 / 影之诗 / 杀戮尖塔玩家；喜欢“算节奏”的中核策略玩家

## 1. 设计出发点：从报告到问题

《主流卡牌游戏设计深度分析报告》里，六款游戏的缺点其实指向几类反复出现的老问题。KAIROS 的核心规则就是针对它们设计的：

| 报告中的痛点 | 出处 | KAIROS 的回答 |
| --- | --- | --- |
| 卡地 / 爆地 / 卡能量 | 万智牌、PTCG | **时间就是唯一资源**，人人都有，不占牌组，不会卡 |
| 资源自动增长后，资源管理就没什么深度了 | 炉石、影之诗 | 时间是**零和**的：你花掉的每一刻都会变成对手的行动窗口，花不花、什么时候花都要算 |
| 无费用导致先手展开太强 | 游戏王 | 没有“回合”，所以不存在“先手回合”；大量展开等于把大段时间让给对手 |
| 先后手不平衡 | 所有对战卡牌 | 时轴行动权天然平衡（落后者行动），只留下极小的起手差，用 +1 手牌补偿 |
| 对手回合没事做、只能看对面打 | 炉石、影之诗、游戏王 | 行动**交错**进行，平均 1–3 刻就换手一次；另有“抢拍”响应，但限制为一问一答 |
| 堆叠规则太复杂 | 万智牌 | 响应只有一层：**一呼一应**，不能再响应对方的响应 |
| 输出型随机过多 | 炉石 | 原则上采用“输入随机”，随机结果**事先摆在时轴上**给双方看 |
| 对局太长 | 万智牌、杀戮尖塔 | 时轴总长 64 刻，从第 48 刻起进入“暮钟”，规则保证对局会结束 |
| 数值膨胀 | 炉石、影之诗 | 用价值点（VP）预算公式约束强度；扩展包优先做横向的新机制 |
| 纯 PvE 缺社交 / 纯 PvP 门槛高 | 杀戮尖塔、万智牌 | 同一套时轴规则同时撑起 PvP、PvE、多人和合作，不用为每个模式重写规则 |
| 收集成本高 | 万智牌、炉石 | 固定内容的套组、可确定合成，付费集中在外观（见第 14 节） |

报告结语问的是：“如何在有限的规则框架内创造无限的策略可能？”
KAIROS 的回答：**只给一种资源，但让它同时决定节奏、信息和互动。**

## 2. 设计支柱

1. **时间即一切（Time is the only currency）**
   费用、抽牌、行动权、终局都由同一条时轴决定。玩家只需要学会一件事：“这一下要花几刻？”
2. **可见的未来（Visible Future）**
   咏唱、敌人意图、随机结果都会提前标在时轴上。信息尽量透明，让人输得明白，延续杀戮尖塔的“数值透明化”。
3. **藏起来的一刻（One Hidden Beat）**
   只有“伏笔”是隐藏信息：对手知道**什么时候**会发生事，但不知道**是什么事**。所有心理博弈都集中在这里。
4. **恰逢其时（Kairos）**
   奖励“精确”：恰好停在钟点上、连续行动、卡着对手咏唱结算前出手。高手和新手的差距主要体现在对时间的计算精度上，而不是规则知识。

## 3. 世界观（简版，完整内容见《KAIROS_世界观与叙事.md》）

**核心命题：谁拥有你的时间？**

**刻律之城**由一台叫“司辰”的 AI 统一分配全城所有人的时间。三十年来效率翻了三倍，人们的可支配时间却越来越少。某天凌晨 4 点 44 分，大钟碎成五块，每一块都承载一种时间观：效率、秩序、代价、预测、延续。十位钟主（跑单十年的信使、八刻法的起草人、透支命烛的急诊医生、算法工程师、92 岁的钟表匠、回乡开雨天书店的年轻人……）为了决定新大钟的规则，在钟楼之巅决斗。

这个世界对应的现实话题包括：算法排班、注意力经济、内卷与躺平、离线权、AI 代理、数字永生、老龄化。PvE 终章揭示：**司辰是自己碎掉的**，因为它发现“替人做决定”本身就是幸福无法达成的原因。

- 美术方向：黄铜齿轮 + 东方节气意象（晨钟暮鼓、日晷、星盘、琥珀）
- 视觉母题：每张卡左上角是一个小钟面，指针所指的刻度就是时值
- 听觉母题：每次行动有一声“滴答”，钟点有钟声，伏笔揭示时有逆向的倒带音

## 4. 核心规则

### 4.1 组件

| 组件 | 说明 |
| --- | --- |
| 时轴 | 0–64 刻，每 4 刻一条**钟点线**（共 16 小节）。实体版可以做成环形钟盘 |
| 时标 | 每位玩家一枚，标记自己在时轴上的位置（实体版可做成“指针”） |
| 牌组 | 30 张；同名最多 2 张，传说最多 1 张；最多 2 个学派 |
| 钟主 | 1 张，决定主学派，提供被动和“时器技能” |
| 命烛 | 生命值，初始 20 |
| 时砂 | 资源标记，主要由暮学派产生，可以减少时值 |
| 侍从区 | 每方 5 个位置 |
| 往昔 | 弃牌堆 / 墓地 |

### 4.2 时轴与行动权（最核心的规则）

> **时标较小（落后）的一方行动。**
> 每次行动都要支付时值，也就是把自己的时标向前推进相应刻数。行动结束后，重新比较双方时标。

- **平局规则**：双方时标相同时，**后到达该位置的一方先行动**（与 Patchwork 相同）。
- **开局**：双方都在第 0 刻。随机决定先行者；后行者起手多抽 1 张。起手 5 / 6 张，可调度一次。
- **连续行动**：只要你仍然落后，就可以一直行动。所以花 6 刻的大招，意味着对手可能拿到连续 6 刻的操作时间。
- **每次行动净耗时至少 1 刻**：任何减费效果都不能让一次行动的花费低于 1 刻。这条规则从根上杜绝了无限循环。

### 4.3 行动类型

每次获得行动权时，选择以下一项：

| 行动 | 耗时 | 说明 |
| --- | --- | --- |
| 打出卡牌 | 卡牌时值 | 受“视界”限制（4.5） |
| 侍从攻击 | 侍从的**节奏**（默认 1） | 每个侍从每小节最多攻击一次，攻击后进入疲惫 |
| 时器技能 | 见钟主 | 钟主的主动技能 |
| 蓄势 | 2 刻 | 抽 1 张牌，每小节限 1 次 |
| 伏笔 | 2 刻 | 将任意一张手牌面朝下埋到时轴上（4.8） |
| 静候 | 移动到对手时标 +1 | 相当于“过”，把行动权交给对手 |

### 4.4 鸣钟（Chime）

当你的时标**到达或越过**一条钟点线（第 4、8、12……刻）时，你会“鸣钟”：

1. 抽 1 张牌（手牌上限 8）
2. 重整：你的所有侍从解除疲惫
3. 视界 +1
4. 触发你的所有“鸣钟时”效果（例如蓄力）

- 一次行动越过多条钟点线，就逐条结算。
- **每条钟点线对每位玩家只鸣响一次。** 时标后退以后再次越过同一条线，不会再鸣钟，所以“倒带刷抽牌”行不通。
- 推论：抽牌速度只跟时间有关，与行动次数无关。打快牌和打慢牌的人，拿到的牌一样多。

### 4.5 视界（Horizon）

> 单次行动能支付的最大时值 = **2 + 你的已鸣钟次数**，上限 7。

开局时视界为 2，每鸣钟一次 +1；最早在第 20 刻（第 5 次鸣钟）达到上限 7。视界按鸣钟次数计算，所以时标后退不会降低视界。视界校验的是**最终费用**，因此时砂可以让暮学派提前打出大牌。
视界提供了类似“法力曲线”的成长感，又不需要额外的资源计数。

> 设计注：视界是第一个需要实测的旋钮。备选方案是完全不设视界，只靠“大牌让出大段时间”来自我约束。

### 4.6 侍从与战斗

- 侍从入场时处于**疲惫**状态（迅捷除外），在你的下一次鸣钟时重整。
- 攻击时，由攻击者选择目标：敌方侍从或敌方钟主（直接扣命烛）。
- 如果敌方有“守卫”侍从，必须先攻击守卫。
- 双方同时造成伤害（与炉石相同）。
- **节奏**：攻击一次要花的时间。轻装侍从是 1，重型侍从是 2 或 3。这是侍从的第三条数值，除了攻和血，还决定了它“出手快不快”。

### 4.7 抢拍（Interject）：一呼一应

对手**宣言**一个行动（打出卡牌、侍从攻击）之后、结算之前，你可以打出一张带【抢拍】的牌：

- 支付 **时值 + 1**（多出来的 1 刻叫“抢拍税”）。
- 即使你当前领先也可以抢拍，代价是你领先得更多，之后对手会拿到更长的行动窗口。
- 你的抢拍牌先结算，然后对手的原行动再结算（如果它仍然合法）；如果原行动不再合法，它会失效，但对手**照付时间**。
- **一呼一应**：每个行动最多被抢拍一次，原行动者不能再响应这次抢拍。
- 抢拍牌也可以在自己行动时**正常打出，不付税**。标注“仅限”的抢拍牌除外（例如拦截者、时空回溯）。
- 宣言打出卡牌、攻击、使用时器技能时会开抢拍窗口；蓄势、伏笔、静候不开窗口。

**通用结算顺序：先效果，后时间。** 行动的效果在你的“出发时刻”结算，结算完之后你的时标才前进。时标前进途中踩到的伏笔、咏唱和钟点，都在效果之后处理。

> 这条规则的目标：保留万智牌“对手出手时我也能做点什么”的紧张感，同时避开它的堆叠复杂度。

### 4.8 时轴物件：咏唱、伏笔、回响

时轴上除了时标，还可以放**物件**。双方都能看到物件所在的位置。

**【咏唱 X】（公开）**
- 支付时值后，把这张牌**正面朝上**放到“你支付后的时标 + X”的位置。目标在宣言时锁定，并对双方公开。
- 当**你的**时标到达或越过该位置时结算。锁定的目标如果已经离场，效果失效，不会重新选择目标。
- 对手可以看到它是什么、什么时候生效，并可以设法推迟、打断，或者在它生效前抢先打死你。
- 每人同时最多 2 个咏唱。

**【伏笔】（隐藏）**
- 花 2 刻，把**任意一张手牌**面朝下放到“你支付后的时标 +1 至 +6”之间的任意一刻。这个位置必须是**双方时标都还没到达**的。
- **任意一方**的时标先到达或越过该位置时，伏笔揭示。造成这次移动的一方叫“触发者”（被推迟越过的玩家也算）。
- 如果揭示的是带【伏笔】关键词的牌，就执行它的“揭示时”效果；否则这是**虚张声势**，直接进入往昔，没有效果。伏笔牌只能盖放，不能正面打出。
- 每人同时最多 3 个伏笔。
- 伏笔会制造这样的问题：“第 18 刻有个盖着的东西，我是现在越过去，还是拖到对手先碰它？”

**【回响 N】**
- 这张牌结算后，在 N 刻之后的位置放一个公开的“回声”物件（效果减半，向下取整），回声同样由你的时标触发。

### 4.9 胜负、逆流与暮钟

- **胜利**：将对手的命烛降至 0。
- **逆流（追赶机制）**：你的命烛**第一次**降到 10 或以下时，你的时标立即**后退 2 刻**。落后的一方会多出一小段连续行动时间，这个思路参考了 PTCG 奖品卡和影之诗复仇机制。
- **暮钟（终局保障）**：从第 48 刻起，你每次鸣钟都要受到暮钟伤害，依次为 1 / 2 / 3 / 4。
- **时尽**：双方都到达第 64 刻时，命烛较高者获胜；如果相同，按以下顺序比较：场上侍从攻击力总和，然后是手牌数，最后判平。

### 4.10 时序结算规则（摘要，完整定义见规格书）

1. **先效果，后时间**：效果结算完，时标才逐刻前进（规格书 R-5-5）。
2. 时标每前进一刻，依次处理：伏笔 → 自己的咏唱 → 鸣钟（R-6-2）。
3. 契机和连拍在**宣言时**锁定。任何行动的宣言（包括对手的抢拍）都会打断你的连拍（R-5-3、R-5-4）。
4. 被推迟的玩家照常逐刻前进：会踩到伏笔、触发自己的咏唱，也会鸣钟（R-6-6）。推迟单次最多 3 刻，每名玩家在其每个小节里累计最多被推迟 4 刻。
5. 任何后退都不能让你落后对手超过 4 刻（R-6-3）。时值的最终下限为 1。
6. 触发器按 FIFO 队列结算。同一批触发中，当前行动者的触发先入队（R-9）。

### 4.11 一页纸速查

```
┌───────────────────────── KAIROS 速查 ─────────────────────────┐
│ 谁行动？      时标落后的人。平局 → 后到者先行                │
│ 费用？        时值 = 你的时标前进几刻                         │
│ 能出多贵的？  视界 = 2 + 已鸣钟次数（上限 7）                 │
│ 抽牌？        每越过一条钟点线（4/8/12…）抽 1、重整、视界+1   │
│ 攻击？        花侍从的节奏（通常 1 刻），每小节 1 次          │
│ 对手出手时？  打【抢拍】牌，多付 1 刻，只能一呼一应           │
│ 咏唱？        公开放在未来，你的时标走到才生效                │
│ 伏笔？        2 刻盖一张到未来，谁先踩到谁触发，可以是假的    │
│ 赢？          命烛 20 → 0；≤10 时逆流后退 2 刻；48 刻后暮钟   │
└───────────────────────────────────────────────────────────────┘
```

## 5. 关键词表

基础系列一共 14 个关键词。新手教程只教前 6 个。

| 关键词 | 规则 | 设计意图 |
| --- | --- | --- |
| **部署** | 入场时触发 | 基础（等同于战吼） |
| **余音** | 离场时触发 | 基础（等同于亡语） |
| **守卫** | 敌方必须先攻击它 | 基础（等同于嘲讽） |
| **迅捷** | 入场时不疲惫 | 快攻 |
| **抢拍** | 可以在对手宣言行动时打出（+1 刻） | 对手回合的互动 |
| **咏唱 X** | 延后 X 刻公开结算 | 预告式强力效果 |
| **伏笔** | 揭示时触发 | 心理博弈 |
| **契机** | 如果这次行动让你的时标**恰好停在钟点线上**，获得额外效果 | 精确计算的奖励，是游戏的签名机制 |
| **连拍** | 如果你上一个行动之后对手没有行动过（你在连续行动），获得额外效果 | 连招奖励（参考影之诗精灵的连击） |
| **蓄力** | 你每次鸣钟时，这个侍从 +1/+1 | 长线成长 |
| **停滞** | 立即疲惫；停滞期间不能被任何效果重整；其控制者的下一次鸣钟只解除停滞、不重整 | 控场 |
| **推迟 X / 加速 X** | 移动时标或时轴物件 | 时间操控 |
| **预见 X** | 查看牌库顶 X 张，任意排序，或将任意张置底 | 稳定性 |
| **回响 N** | N 刻后再结算一次减半的效果 | 时间维度上的复制 |

## 6. 五时学派（颜色轮）

五个学派围成一个钟面。相邻的学派是盟友，正对的学派是宿敌。

```
                 ☀ 昼 · 烈阳
              （秩序 / 守护）
           ↗                  ↘
  🌅 晨 · 破晓                 🌇 暮 · 余烬
  （抢先 / 速攻）              （代价 / 轮回）
          ↖                   ↙
   🟠 永 · 琥珀  ←──→  🌌 夜 · 星轨
  （成长 / 停滞）      （预言 / 命运）
```

| 学派 | 时间哲学 | 核心机制 | 强项 | 刻意缺失 |
| --- | --- | --- | --- | --- |
| 🌅 **晨·破晓** | “时间是用来抢的。” | 迅捷、抢拍、连拍 | 低时值、高频行动、打脸 | 后期大牌、回复 |
| ☀ **昼·烈阳** | “时间应当有序。” | 守卫、护盾、推迟物件、回复 | 防守、反制咏唱、条件解场 | 抽牌、爆发 |
| 🌇 **暮·余烬** | “一切终将逝去，代价可以换取时间。” | 余音、牺牲、时砂、往昔回收 | 资源转换、减费爆发 | 守卫、回复 |
| 🌌 **夜·星轨** | “未来早已写定。” | 咏唱、伏笔、预见、预言 | 信息优势、大型咏唱、反制 | 前期侍从 |
| 🟠 **永·琥珀** | “我有的是时间。” | 蓄力、停滞、推迟对手时标 | 慢速成长、拖时间、巨型侍从 | 抢拍、直伤 |

## 7. 钟主（英雄）

钟主相当于炉石英雄与影之诗进化点的结合：一个常驻被动，加一个按时间冷却的时器技能。基础系列每个学派 2 名钟主，共 10 名。下面是每个学派的第一位。

| 钟主 | 学派 | 被动 | 时器技能 |
| --- | --- | --- | --- |
| **破晓者 · 伊琳** | 晨 | 每小节你的第一次抢拍不需要付抢拍税 | 「晨鸣」1 刻：本小节入场的一名友方侍从获得迅捷。每小节 1 次 |
| **执钟者 · 奥瑞斯** | 昼 | 你的守卫侍从 +0/+1 | 「正午裁定」1 刻：推迟一个时轴物件 2 刻。每 2 小节 1 次 |
| **焚时者 · 摩尔甘** | 暮 | 每小节首个死亡的友方侍从使你获得 1 时砂 | 「焚时」1 刻：支付 2 命烛，抽 1 张。每小节 1 次 |
| **观星者 · 塞勒涅** | 夜 | 你随时可以查看自己的牌库顶 | 「窥时」1 刻：从牌库顶 3 张中选 1 张加入手牌，其余置底。每 3 小节 1 次 |
| **守年人 · 古尔德** | 永 | 你的侍从以“契机”入场时 +1/+1 | 「凝滞」2 刻：停滞一名时值 ≤3 的侍从。每 2 小节 1 次 |

**钟主觉醒（基础规则中预留）**：每名钟主有一个觉醒条件（例如伊琳“累计抢拍 3 次”），达成后时器技能升级。觉醒在扩展 4 中正式启用，见第 12 节。

## 9. 对局示例

预组 A（P1，伊琳）对预组 B（P2，奥瑞斯）。P1 被随机选为先行者，P2 起手 6 张。下表严格按规格书的规则推演；“→”表示行动后的时标位置。

| # | 行动者 | 行动 | 时标 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | P1@0 | 晨光斥候（1） | P1→1 | 迅捷，入场即可行动。视界 2 |
| 2 | P2@0 | 正午卫士（2） | P2→2 | 奥瑞斯被动：守卫 +0/+1，所以是 1/5 |
| 3 | P1@1 | **伏笔**（2）：盖下“虚空凝视”，放在第 7 刻 | P1→3 | 支付后时标为 3，可选范围是 4–9，且必须 > P2 的时标 2。P2 只知道“第 7 刻有东西” |
| 4 | P2@2 | 萌芽种子（1） | P2→3 | 双方都在 3，P2 后到，所以 P2 继续行动 |
| 5 | P2@3 | 晨祷修士（1） | P2→4 | **鸣钟**：抽 1、视界 3、重整；种子蓄力 → 1/3 |
| 6 | P1@3 | 星陨（1），**咏唱 4**，锁定目标为正午卫士 | P1→4 | 咏唱放在 3+1+4 = **第 8 刻**，双方可见。P1 鸣钟：视界 3。双方都在 4，P1 后到，P1 继续 |
| 7 | P1@4 | 疾行信使（2），**连拍**（上一个宣言者也是 P1）→ 抽 1 | P1→6 | |
| 8 | P2@4 | **正常打出**秩序之刻（1，自己行动时不付税），把星陨从第 8 刻推迟到**第 11 刻** | P2→5 | 为卫士争取时间 |
| 9 | P2@5 | 琥珀封印（2）停滞疾行信使 | P2→7 | P2 本可以只走 1 刻、停在 6，但手里没有合适的 1 刻牌，于是主动踩下第 7 刻的伏笔：**虚空凝视揭示**，P2 打出的下一张牌时值 +2 |
| 10 | P1@6 | 黎明骑手（3），迅捷；上一个宣言者是 P2，所以没有连拍 | P1→9 | 越过第 8 刻时鸣钟：视界 4；疾行信使的停滞在这次鸣钟中解除，但它这次不重整 |
| 11 | P2@7 | 苔藓守望者要 2+2 = 4 刻，超过视界 3，**不能打**。改为卫士攻击斥候（1） | P2→8 | 开抢拍窗口，P1 不抢拍。斥候死亡，卫士剩 1/3。P2 鸣钟：视界 4；种子 → 2/4 |
| 12 | P2@8 | 苔藓守望者（2+2 = 4，虚空凝视的效果被消耗） | P2→12 | **先效果后时间**：苔藓先入场，P2 走到第 12 刻鸣钟时，苔藓已经能蓄力 → 2/4，种子 → 3/5。代价是 P1 获得了 9→12 的连续行动 |
| 13 | P1@9 | 观星学徒（1），预见 2 | P1→10 | |
| 14 | P1@10 | 沙漏（1），抽 1 | P1→11 | 到达第 11 刻：**星陨结算**，对卫士造成 4 点伤害，卫士死亡 |
| 15 | P1@11 | 守卫已经不在，黎明骑手攻击 P2 钟主（1） | P1→12 | P2 命烛 20 → 17。P1 停在第 12 刻，这次行动恰好是契机（本次行动的牌不受益）；P1 鸣钟，视界 5。双方都在 12，P1 后到，P1 继续 |

这段开局展示了：
- **平局规则**会制造连续行动（第 4、6、15 步）；
- **伏笔**改变了对手的路线规划。P2 在第 9 步主动踩伏笔，在第 11 步就因为视界不够而付出了代价；
- **咏唱**是公开的。P2 在第 8 步把星陨推迟了 3 刻，却把卫士的生存时间拖到了 P1 的连续行动窗口里；
- **先效果后时间**让“一次性走很远”的大动作也有收益（第 12 步）；
- 每次行动只花 1–4 刻，换手非常频繁，**没有人在“等对面”**。

数字版需要在时轴上持续高亮“下一个行动者”，并用幽灵预览显示“这张牌打出后，对手会得到几刻连续行动”（见第 13 节）。

## 10. 平衡框架

### 10.1 价值点（VP）预算

| 要素 | VP |
| --- | --- |
| 1 刻时值 | 2 |
| 卡牌基础预算 | 时值 × 2 + 1（时值 1 的牌额外 +1，因为它同样占一张手牌） |
| 1 攻 / 1 血 | 1 / 1 |
| 抽 1 张 | 3 |
| 直伤 1 点 | 1.5 |
| 恢复 1 点 | 0.5 |
| 推迟对手时标 1 刻 / 加速自己 1 刻 | 2 |
| 迅捷 | 1 |
| 守卫 | 0.5 |
| 蓄力 | 2 |
| 节奏每 +1 | -1 |
| 抢拍 | 0（价值已经由抢拍税支付） |
| 咏唱每延后 2 刻 | 预算 +1 |
| 连拍 / 契机条件效果 | 按效果 VP × 0.5 计 |

**示例核算**
- 晨光斥候：时值 1，预算 2+1+1 = 4；2/1 = 3，加迅捷 1 = 4 ✔
- 黄铜魔像：时值 4，预算 9；5/5 = 10，节奏 2 扣 1 = 9 ✔
- 星陨：时值 1，预算 4，咏唱 4 再加 2 = 6；4 点伤害 = 6 ✔

### 10.2 护栏规则（Design Guardrails）

1. **净耗时下限为 1**：不允许零费循环。
2. **加速限幅**：任何加速都不能让你的时标落后对手超过 4 刻，防止人为制造超长的连续回合。
3. **单次推迟对手 ≤ 3 刻**：控场可以拖慢对手，但不能把对手“锁死”。
4. **随机原则**：不出现“随机造成 1–10 伤害”这类输出随机。随机效果必须**在放上时轴时就决定结果并公开**，或者采用发现式的三选一。
5. **横向扩展**：新系列优先引入新关键词或新的时轴物件，同一时值的身材上限保持不变。

### 10.3 核心平衡指标（KPI）

| 指标 | 目标值 | 主要调节旋钮 |
| --- | --- | --- |
| 先行者胜率 | 48–52% | 后行者额外手牌、平局规则 |
| 平均对局时长（数字版） | 10–15 分钟 | 命烛、暮钟起点 |
| 平均换手间隔 | 1.5–2.5 刻 | 卡池时值分布 |
| 平均抢拍次数 / 局 | 3–6 次 | 抢拍税、抢拍牌密度 |
| 进入暮钟的对局比例 | 15–25% | 命烛、伤害曲线 |
| 逆流后的翻盘率 | 25–35% | 逆流的后退刻数 |
| 单卡在卡组中的胜率贡献 | 与均值偏差 ≤ ±3% | VP 预算 |

## 11. 游戏模式

同一套时轴规则，可以自然延伸出以下模式。

### 11.1 天梯构筑（核心 PvP）
- 30 张牌组 + 1 钟主，Bo1 / Bo3。
- 不做卡牌轮替。改用“**时令赛制**”：每个赛季精选一个卡池子集作为特色赛制，与“永恒赛制”（全卡池）并存。

### 11.2 时砂轮抽（Draft）
- 2 人版：桌面摆一排 6 张公共卡（“时之市”），每张卡标有**轮抽时值**（稀有度越高越贵）。双方各有一条轮抽时轴，**落后者挑牌**。把对局规则原样搬到选牌阶段。
- 8 人版：传统三轮开包轮抽。

### 11.3 逆流之塔（Roguelike PvE）

时轴系统天然适合做 PvE：**敌人也是时轴上的行动者，它的下一步意图直接放在时轴上。**

```
时轴：  …  12 ── 13 ── 14 ── 15 ──|16 ──
你：          ▲
敌人·钟楼傀儡：                ⚔ 重击 12（第 15 刻）
                                         🛡 格挡 8（第 17 刻）
```

- 杀戮尖塔的“意图”只告诉你**做什么**；这里还告诉你**什么时候做**。玩家可以抢在第 15 刻之前击杀敌人，用推迟把重击挪到格挡之后，或者故意拖延。
- **结构**：晨、昼、夜三幕，每幕约 15 个节点（战斗 / 精英 / 篝火 / 商店 / 事件 / 宝箱 / Boss）。
- **角色**：钟主作为角色，有初始牌组（10 张）和专属卡池。
- **齿轮（遗物）**：改变底层规则，例如：
  - 「发条心脏」：每次触发契机，恢复 2 命烛。
  - 「逆旋擒纵」：每场战斗第一次鸣钟时，时标后退 1。
  - 「破碎表盘」：视界始终为 7，但每场战斗开始时受到 5 点伤害。
- **调律（篝火）**：升级一张卡，或移除一张卡，或将一张卡“改刻”（时值 ±1，效果相应调整）。
- **裂度 1–20**：进阶难度，例如敌人意图的提前量减少、精英出现伏笔。
- **双人合奏（合作）**：两名玩家与 Boss 共用一条时轴。队友连续行动时触发“合奏”效果。

### 11.4 钟楼乱斗（3–4 人 FFA）
- 所有人共用一条时轴，**最落后的人行动**。传统多人卡牌“等一圈很久”的问题被时轴天然解决。
- 防围攻规则「众矢」：在同一小节内受到 2 名以上对手攻击的玩家，获得一枚“逆流”（后退 1 刻）。
- 胜利：最后存活者胜，或在时尽时比较命烛。

### 11.5 2v2 协奏
- 队友共享命烛（30）和一条时轴，各自有时标。
- 队友的抢拍可以保护你，所以队伍之间需要协调“谁领先、谁殿后”。

### 11.6 残局谜题（每日挑战）
- 例如：“你在第 21 刻，对手在第 23 刻，对手命烛 9。用 3 张手牌，在对手行动前获胜。”
- 解法通常依赖契机或连拍的精确计算，同时可以当作教学关卡。

## 12. 扩展路线

每个扩展引入**一个新的时轴维度**，而不是更大的数值。

| 序号 | 扩展名 | 核心新增 | 设计思路 |
| --- | --- | --- | --- |
| 基础 | 《钟碎之日》 | 五时学派、14 个关键词、10 名钟主 | 建立基础规则 |
| 扩展 1 | 《裂隙悖论》 | **第六学派 · 隙**：预支（现在打出，但在未来给对手补偿刻数）、分身（同一张牌在时轴上存在两个版本）、悖论（如果这次行动让你的时标与对手完全相同，就交换双方时标） | 打破“时间只能向前”的直觉；新学派作为钟面中心的“指针轴”，与五个学派都可以组合 |
| 扩展 2 | 《节气历法》 | **历法卡**：开局时随机抽 3 张公开的全局事件，放在时轴固定刻度，例如第 20 刻“日蚀：所有侍从 -1 攻”、第 36 刻“惊蛰：双方各抽 2 张” | 给对局加入“地图路线”式的规划，同时保持公开信息、输入随机；可作为赛季轮换的内容 |
| 扩展 3 | 《双轴》 | **副时轴**：某些刻印卡会开启一条只属于你的短副轴，副轴上的物件只由你的“副时标”推进 | 高复杂度构筑空间，留给硬核玩家 |
| 扩展 4 | 《古钟觉醒》 | **钟主觉醒**：达成条件后升级时器技能；新增可以在对局中更换的“副钟主” | 给中盘一个转折点，作用类似影之诗的进化 |
| 扩展 5 | 《时间商人》 | **公共市场**：对局中开放一排可以花时间购买的公共卡，引入 DBG（如 Dominion）的元素 | 降低构筑门槛，可以衍生休闲模式 |
| 衍生作 | 《钟楼战棋》 | 侍从按节奏**自动**行动的自走棋 | 侍从的节奏属性天然对应自走棋的“攻速”，可以复用卡牌资产 |

**机制储备池（未来系列备选）**
- 「残响」：侍从死亡后在时轴上留下一个幽灵物件，若干刻后复活。
- 「借时」：向对手“借”2 刻，现在立即行动；之后一旦对手落后，你必须让出 2 刻。
- 「同步」：两张同名牌恰好在同一刻结算时触发强力合体。
- 「钟摆」：效果在两种状态间来回切换，每次鸣钟切换一次。
- 「倒影伏笔」：只有对手才能看到内容的伏笔（反向信息差）。

## 13. 数字化与实体化

### 13.1 数字版界面线框

```
┌────────────────────────────────────────────────────────────┐
│ 奥瑞斯  命烛 17  手牌 5  视界 4    时器：正午裁定(就绪)   │
│ [卫士 1/4🛡] [种子 2/4🌱] [   ] [   ] [   ]               │
├──────────────────────── 时 轴 ─────────────────────────────┤
│  8 ┊  9   10   11  ┃ 12   13   14   15 ┃ 16               │
│         ▼P2(你方下一个对手)                                │
│      ▲P1          ◆?(伏笔)        ★星陨→卫士(你的,第15刻)  │
│   ▶ 下一个行动者：你        若打出【黎明骑手】→ 对手连动 3 刻 │
├────────────────────────────────────────────────────────────┤
│ [骑手 3/3⚡] [斥候 2/1⚡] [   ] [   ] [   ]                │
│ 伊琳  命烛 14  时砂 0  视界 4      时器：晨鸣(就绪)       │
│ 手牌: [破晓一击·抢拍1] [疾风连奏2] [沙漏1] [曙光洪流5]     │
└────────────────────────────────────────────────────────────┘
```

**数字原生功能**
- **时间幽灵预览**：鼠标悬停在一张牌上时，时轴显示“打出后你的时标位置、你会触发什么、对手会获得几刻连续行动”。这是降低计算门槛的关键。
- **持续高亮下一个行动者**：解决平局规则的理解成本。
- **抢拍窗口**：只在你手里有可用的抢拍牌时弹出，并配一个短倒计时，不会每个行动都询问。
- **复盘时轴**：赛后可以拖动时轴回看每一刻，方便观战和教学。
- **观战友好**：观众可以随时看到“谁下一个行动、还剩几刻”，比回合制更容易制造“抢时间”的悬念。

### 13.2 实体版组件

- 环形钟盘版图（64 刻，16 小节）和两枚指针型时标
- 时轴物件卡架：咏唱正面朝上、伏笔背面朝上，插在钟盘外圈
- 时砂标记、命烛转盘、疲惫用横置
- 规则保持完全一致，不需要实体专属规则（这是设计约束：**任何机制都必须能在桌面上实现**，扩展 3 除外）

## 14. 商业化与长线运营

> 以下为长期方向，不等于当前 Demo 功能。用户已选择「收集构筑」；具体机制与首期范围见 [局外收藏与成长系统](KAIROS_局外收藏与成长系统.md)。该审阅稿建议先做免费预组、结算铸片与指定合成；卡包、主动分解、付费和赛季运营均后置，奖励数值待测试。

| 方向 | 方案 | 回应报告中的痛点 |
| --- | --- | --- |
| 卡牌获取 | 免费：完成每日与赛季任务获得卡包；**可确定合成**（分解碎片合成指定卡） | 全卡收集压力大 |
| 付费主体 | 外观：钟主皮肤、钟盘主题、指针特效、卡牌异画、钟声音效包 | 降低付费与强度的关联 |
| 可选买断 | 每个扩展提供“完整套组”一次性买断（类似 LCG） | 收集成本高 |
| 赛制 | 永恒赛制 + 时令赛制，不强制轮替 | 退环境导致卡牌贬值 |
| 平衡 | 每两周根据数据微调，**调弱卡牌全额返还碎片** | 禁限表争议 |
| 运营内容 | 每月一张“历法事件”（扩展 2 的机制），不加新卡也能刷新环境 | 环境固化 |
| PvE | 逆流之塔作为独立买断 DLC 或包含在通行证内；PvE 解锁内容**不影响 PvP 强度** | 维护 PvP 的公平性 |

## 15. 风险与对策

| 风险 | 表现 | 对策 |
| --- | --- | --- |
| **算力疲劳（AP）** | 玩家需要不停计算刻数 | 数字版的幽灵预览；卡牌时值集中在 1–4；第一个教程只开放 1–2 刻的牌 |
| **平局规则反直觉** | 新手搞不清“为什么又是我” | 持续高亮下一个行动者；教程第 2 关专门演示平局规则 |
| **大牌窗口失衡** | 7 刻大招让对手连动 7 刻，可能一边倒 | 视界限制；暮钟；用数据决定大牌是否需要“咏唱化” |
| **控制卡组锁死对手** | 推迟 + 停滞让对手长时间无法操作 | 单次推迟 ≤3 的护栏；“被推迟的刻数”在本小节累计达到 4 后免疫推迟 |
| **伏笔的挫败感** | 踩到伏笔被直接解场 | 伏笔效果整体比同时值的公开牌弱 10–20%；虚张声势比例由设计控制（基础系列每学派只有 1–2 张真伏笔） |
| **抢拍拖慢数字版节奏** | 每个行动都要等对手响应 | 只在对手持有可用抢拍牌时才开窗口；但为了不泄露“你手里有抢拍”，也会**随机插入假窗口** |
| **先行优势残留** | 首次行动带来微弱优势 | 后行者 +1 手牌；如果数据显示仍有偏差，改为后行者从第 0 刻开始、先行者从第 1 刻开始 |
| **主题与机制脱节** | 时间主题玩着像普通费用 | 所有关键词的命名和动画都直接表现时间（倒带、钟声、指针） |

## 16. 原型开发与验证计划

### 阶段 0：纸面原型（1–2 周）
- 材料：一条打印出来的 0–64 时轴、两枚棋子、第 8 节的两套预组（打印卡片或在空白卡上手写）、骰子充当命烛和时砂。
- 测试问题：
  1. 前 5 局中，玩家是否自发地讨论“要不要踩伏笔”？
  2. 平均换手间隔是否在 1.5–2.5 刻之间？
  3. 视界开启和关闭，哪种更好玩？
  4. 抢拍出现的频率，以及它带来的感受（紧张还是烦躁）？

### 阶段 1：规则引擎与模拟器（2–4 周）
- 按规格书在 Unity 项目中实现纯 C# 规则引擎（`Kairos.Engine` 程序集，不引用 UnityEngine），并用 NUnit 跑通规格书第 20 节的验收用例。
- 用 .NET 8 控制台工程 `Tools/Kairos.Sim` 链接同一份引擎源码，接入 AI（贪心 + ISMCTS）进行大规模自我对弈。
- 输出：先行者胜率、对局长度分布、单卡胜率贡献、进入暮钟的比例。
- 用途：批量扫描参数，例如命烛 18–24、钟点间隔 3–5 刻、抢拍税 0–2，找到第 10.3 节 KPI 的达标区间。这也是报告“未来展望”里 **AI 辅助平衡**的落地方式。

### 阶段 2：数字垂直切片（6–8 周）
- 引擎：**Unity 6 LTS（C#）**，直接复用阶段 1 的规则引擎；客户端只负责表现（事件驱动动画）和输入。
- 范围：双人本地对战、两套预组、完整的时轴 UI（重点做幽灵预览）、新手教程前 3 关、本地 AI 对手。
- 验证：新玩家不看规则书、只走教程，能否在 15 分钟内打完第一局？

### 阶段 3：扩充与 PvE（8–12 周）
- 补全五个学派的 100 张卡，做出逆流之塔第一幕（15 个节点、3 种精英、1 个 Boss），开放小规模线上测试。

## 17. 附录

### 17.1 机制溯源（每个机制借鉴了什么，改了什么）

| KAIROS 机制 | 灵感来源 | 改造点 |
| --- | --- | --- |
| 时轴行动权 | 桌游 Patchwork / Tokaido、JRPG 的 ATB | 首次用作对战 CCG 的唯一资源 |
| 视界 | 炉石的法力水晶增长 | 只用来限制上限，不再是可消耗的资源 |
| 抢拍 | 万智牌的瞬间与堆叠、游戏王的手坑 | 只有一层，且需要付出时间代价 |
| 伏笔 | 游戏王的盖卡、炉石的奥秘 | 公开“何时”、隐藏“何事”，并允许虚张声势 |
| 咏唱 | 杀戮尖塔的敌人意图、影之诗主教的吟唱 | 让玩家自己的强力效果也变成公开预告 |
| 逆流 | PTCG 的奖品卡、影之诗吸血鬼的复仇 | 追赶的方式是给时间，而不是给数值 |
| 五时学派 | 万智牌的颜色轮 | 用时间哲学来区分学派 |
| 钟主时器 | 炉石的英雄技能、影之诗的进化点 | 冷却按小节计算，并且有觉醒的扩展空间 |
| 齿轮 / 逆流之塔 | 杀戮尖塔的遗物与爬塔结构 | 敌人意图带有精确的时间点 |
| 时砂轮抽 | 万智牌的限制赛 | 选牌阶段同样使用时轴 |
