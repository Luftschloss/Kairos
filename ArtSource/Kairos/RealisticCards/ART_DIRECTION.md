# KAIROS 写实卡牌美术 · 钟碎之日

制作依据：`docs/KAIROS_世界观与叙事.md`、`docs/data/cards.json`，对应现有 46 张卡牌与 10 名钟主。用户要求写实风格、类似昆特牌的效果；制作使用已授权的 imagegen API/CLI 入口和项目配置的模型。

## 画面目标

写实暗色奇幻叙事绘画：可信的人体与面部表情、经历使用的布料/皮革/黄铜、光照下具有重量的机械、前中后景空间。人物表达其与时间的关系，术式表达一次具体事件。参考昆特牌式卡牌插画的材质、构图与光影质感，角色、道具和故事均来自 KAIROS。

城市由黄铜、玻璃、石桥、巨型钟楼和层叠街道构成。腕钟是调度终端；时砂是被浪费时间的结晶；命烛象征生命；司辰是试图最大化幸福却主动解体的中枢。画面表现普通劳动者的尊严，避免把所有人改成贵族、法师或战士。

| 学派 | 色彩与光线 | 画面语言 |
|---|---|---|
| 中立 | 黄铜、炭灰、冷蓝环境光 | 手艺、城市日常、机械重量 |
| 晨 | 铜橙晨光、蓝灰阴影 | 斜线动势、信使、风与疾行 |
| 昼 | 象牙白、旧金、高窗日光 | 守护、照护、制度与边界 |
| 暮 | 余烬铜红、暗酒红、紫灰 | 消耗、旧物、回声与记忆 |
| 夜 | 靛蓝、银白、少量紫光 | 实体星盘、科学、概率与未知 |
| 永 | 苔绿、蜂蜜琥珀、柔光 | 自然、生长、慢生活与岁月 |

## 交付约束

- 每个 Key 一张独立画面；人物年龄、职业和动机优先遵循文档。
- 插画不包含卡名、数字、规则、边框和 UI，文字由现有 Unity Prefab 渲染。
- 原图请求 1024×1536、高质量 PNG；导入版裁切为 3:4，再缩放到 768×1024。保持主体在中央安全区，考虑不同卡牌 Prefab 的裁切。
- 明暗层次应在小图上仍可读，不把暗色等同于黑成一团。
- 不使用几何剪影、线稿、版画刻线、低多边形、卡通或塑料材质。
- `scenes.json` 中对服装、视角、动作的补充是美术设计解释，不更改游戏设定或数值。
- 原图、提示词、来源哈希及导入记录保存在本目录；原版可编辑 SVG/ORA 保留于 `EtchedCards`。

## 文件

- `prompts/<Key>.txt`：实际提交的完整提示词。
- `originals/<Key>.png`：服务返回的原图。
- `manifest.json`：卡牌清单、来源哈希、画面描述与请求参数。
- `jobs.remaining.jsonl`：待生成且未已有完整文件的任务。
- `contact-*.jpg`：整套及分学派总览，供视觉检查。
- `integration.json`：导入时的源图/运行图哈希与原 GUID。

自动化生成只是制作环节；最终仍需检查角色设定、面部/手部、构图、风格与缩图后的可读性。
